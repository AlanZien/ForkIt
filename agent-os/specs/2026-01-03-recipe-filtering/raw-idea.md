# Raw Idea

Recipe Filtering by Preferences - Filter recipe search results and suggestions based on user's dietary preferences and allergies. Exclude recipes containing allergens or incompatible ingredients.

**Context:**
- ForkIt is a French meal planning mobile app (React Native + FastAPI + Supabase)
- Users already have a profile with dietary preferences (végétarien, sans porc, halal, etc.) and allergies (gluten, lactose, fruits à coque, etc.)
- Recipe browsing with TheMealDB is already implemented
- This feature should filter recipes based on user preferences stored in Supabase
